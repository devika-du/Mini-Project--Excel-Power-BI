## Overview

This project presents an analysis of rice price, demand, supply, and weather-related data using **Microsoft Excel** and **Power BI**.

The project focuses on transforming raw rice market data into meaningful insights through data cleaning, analysis, visualization, and an interactive Power BI dashboard.

## Project Objectives

The main objectives of this analysis are:

- Analyze rice price variations across regions and rice types
- Understand demand and supply patterns
- Identify high and low-priced rice types
- Analyze the relationship between weather conditions and rice prices
- Identify key market trends and insights
- Build an interactive Power BI dashboard for decision-making

## Tools & Technologies

- **Microsoft Excel** – Data cleaning and analysis
- **Power Query** – Data transformation and preprocessing
- **Power BI** – Dashboard development and visualization
- **DAX** – Calculated columns and analysis

## Data Preprocessing

The raw dataset was cleaned and prepared before analysis.

Key preprocessing steps included:

- Handling missing values
- Removing inconsistencies
- Treating unknown values
- Filling missing numerical values using appropriate statistical methods
- Cleaning categorical fields such as Region and Rice Type
- Correcting data type errors
- Formatting numerical and date fields
- Creating calculated columns using DAX

## Key Analyses

- Region-wise Demand and Supply Analysis
- Rice Type-wise Demand Analysis
- Rice Price Analysis
- Import vs Export Analysis
- Rainfall by Region
- Average Rice Price by Year and Rice Type
- Average Temperature by Rice Type
- Weather Condition Analysis

## Power BI Dashboard

The dashboard includes:

### Rice Price Overview
Provides an overall view of rice prices with KPIs and filters for Year, Rice Type, and Region.

### Market & Demand Analysis
Analyzes demand, supply, and regional market patterns.

### Weather & Price Analysis
Explores the relationship between weather conditions and rice prices.

### Insights & Recommendations
Highlights key findings and provides business-oriented recommendations.

## Key Insights

- Basmati rice recorded the highest demand among the rice types.
- Rice prices vary considerably across different rice types and periods.
- Demand and supply patterns differ across regions.
- Weather conditions show variations across regions and can be considered when analyzing price movements.
